## Scope

- Instrument cluster illumination and indicator bulbs
- Climate control and switch backlighting
- Dome, map, and trunk lamps as equipped

## Bulb Selection

- Match the base type exactly (wedge sizes vary inside one cluster)
- Choose brightness that does not overpower warning lamps
- Prefer LEDs that work with the factory dimmer; if the dimmer buzzes or drops out, pick a different driver design
- Color: many factory green filters look wrong with pure white LEDs - test one socket first

## Cluster Access Outline

1. Disconnect the battery (use a memory saver if you care about radio presets).
2. Remove lower column covers and cluster surround screws per the service manual.
3. Extract the cluster; keep screws grouped by length.
4. Replace bulbs one location at a time to avoid mix-ups.
5. If an LED is dark, rotate it 180° - many are polarity sensitive.
6. Power up and prove every warning lamp before final reassembly.

## Interior Lamps

Festoon and wedge interior bulbs usually drop in. Ensure metal ends seat firmly; vibrating LEDs rattle and flicker. Keep cargo/trunk lamps from shining as reverse-beam glare if you raise output substantially.

## Failures and Fixes

| Symptom | Fix |
| :--- | :--- |
| One lamp dark | Reverse LED polarity or reseat |
| Uneven cluster glow | Mixed brightness bins; standardize part numbers |
| Dimmer inoperative | LED electronics incompatible - try another brand or keep incandescent on that circuit |
| Indicator too dim through filter | Higher output or color-matched LED |

## Verification Checklist

- [ ] Key-on lamp prove-out for all warnings
- [ ] Night dimmer sweeps without flicker
- [ ] No loose bulbs after a drive over rough roads
- [ ] No melted sockets (LEDs should run cooler; heat implies wrong part or short)
